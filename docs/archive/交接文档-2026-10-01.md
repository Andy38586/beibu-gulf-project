## 三、怎么做（接任者必须继承的方法与纪律）

1. **证据先行**：结论挂 file:line 或实测输出；负结果必附同形态阳性对照。
2. **预物化+查询层计算**（勘误#5）：因子面一次物化入库，端点只做归一化+加权和。
3. **迁移必迁测**：搬逻辑同笔搬测试——隔离迁移时测试当场抓到两处语义偏差。
4. **决策反转留痕**：推翻既有口径（如面板 8 上限反 c043）必须在测试/注释写"凭什么反、
   红样在哪"。
5. **守卫链是盟友**（本窗口各拦一次真问题）：`routes-audit`（新域要同步前端域清单+
   env 副本）、`cruise`（controller 不得直连 repository；新业务目录要加互引规则）、
   契约反向核对（@backend-contract 指向**真生产者**文件，键位必须在）、commitlint
   （**subject 不以大写字母开头**，如 "POI"开头的标题必拒）。
6. **流程地雷**：`docs/*` 默认 gitignore——新文件要在 `.gitignore` 尾部**逐份放行**；
   `.md` 提交前 `npx prettier --write`（npx 版本与本地可能不一致，--check 过不代表 pre-commit 过）；
   commit message 长证据落 `.local/` 并正文指路（正文行 ≤100 字符）。
7. **服务启停**：`npm run dev:all`（run-p 并行 vite:5173 + Nest:3000，后端 watch）；
   前端 `/nest-api` 经 vite 代理到 3000。**后端必须 `PG_PORT=5432`**（.env 已改好，
   2026-10-01 起）；Docker Desktop 本机常掉线——掉了就
   `"/c/Program Files/Docker/Docker/Docker Desktop.exe" & sleep 45`。
   注意：**React 存档项目不可依赖**；`bgr-review-pg`(15432) 是旧 review 副本库
