# 预测分析模块 — 冻结说明

> v1.5 Architecture Validation Release

---

## 冻结原因

预测分析模块当前面临的核心问题不是代码质量，而是**业务定义缺失**：

1. **指标体系未确定**：真实港口吞吐量、泊位使用率、船舶流量等指标尚未获取
2. **数据源未接入**：当前使用 mock 时序数据（`public/data/forecast/*.json`），不具备业务参考价值
3. **算法目标不明确**：未确定预测模型（LSTM / Prophet / 统计回归）

在缺少真实业务约束的情况下继续优化代码，会导致：
- 数据结构反复调整
- 接口设计无法验证
- 优化方向不确定

**结论**：冻结预测分析业务扩展，等待真实数据接入后重新打开。

| 功能 | 状态 | 说明 |
|------|------|------|

| 地图联动 | ✅ | Heatmap / GeoJSON 图层，`useForecastLayer` 管理 |

| Mock → API 切换 | ✅ | 通过 `forecastAdapter.setDataSource('api')` 切换 |
