## 三、必须说清的「坑」（不是改名就完事）

1. **当前 `.js` 完全不在类型网内** —— `tsconfig.app.json` 的 `checkJs: false`，所以 OLRenderer.js(626 行) / CesiumRenderer.js(871 行) 两大复杂度热点今天仍**零类型检查**。把它们改名 `.ts` 只是「进了类型网」，真正收益要你手写类型注解才到账。
2. **没有 `@typescript-eslint` 插件** —— eslint 只装了 parser，没装插件，开不了 `no-explicit-any`。现在源码里 ~9 处真实 `any`（集中在渲染器边界、地图数据、1 个 API 返回值），改名后若不装门禁，新 `any` 会静默回潮。
3. **结论**：TS 迁移的「数量」已过半，但「质量」（类型覆盖 + 防回退护栏）还是 0。先追求把 `.js` 进网，再逐步补注解，最后装 tseslint 锁死。
