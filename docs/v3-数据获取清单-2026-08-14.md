## 三、可直接下载（脚本已封装，无需注册）

### 3.1 陆地 DEM-30m
- **Copernicus GLO-30**（推荐升级项）：ESA 30m 全球 DSM，质量与空洞处理优于 ASTER，AWS 公开桶直连
  - URL 模式：`https://copernicus-dem-30m.s3.amazonaws.com/Copernicus_DSM_COG_10_N{lat}_00_E{lon}_00_DEM/...tif`
  - 范围：N20-N23 × E106-E110（钦北防+南宁+平陆运河走廊），20 瓦片，每片约 30-60MB
- **SRTM 30m**（备选）：NASA 公开 skadi 瓦片
  - URL 模式：`https://elevation-tiles-prod.s3.amazonaws.com/skadi/N{lat}/N{lat}E{lon}.hgt.zip`
  - 同范围 20 瓦片，每片约 10MB
- 说明：现有 ASTER 6 瓦片保留作对照；处理流程（填洼/重投影）可复用 `tools/dem-pipeline/`

### 3.2 海底 DEM
- **SRTM15+ V2.6**：全球 15 弧秒（≈460m）陆海一体，`https://topex.ucsd.edu/pub/srtm15_plus/SRTM15+V2.6.nc`（约 2.6GB，脚本 `-IncludeBathymetry`）
- **GEBCO 2023**（备选）：`https://www.gebco.net` 全球格网，同样 15 弧秒
- **诚实标注**：15 弧秒对港口尺度（泊位/航道）太粗。港口尺度方案 = 海图水深点数字化（见 §五）或 ENC 电子海图。论文中"区域尺度用 GEBCO/SRTM15+，港区尺度用海图点插值"本身就是数据融合方法点

### 3.3 路网（最短路径模块）
- **OSM China**：`https://download.geofabrik.de/asia/china-latest.osm.pbf`（约 1.4GB，脚本 `-IncludeOSM`）
  - 含全部 `highway=*`（公路）与 `railway=*`（铁路），一次下载两样都有
  - 裁剪广西范围（含钦北防+南宁，bbox 约 106.5,20,110.5,24）：`osmium extract -b <bbox> china-latest.osm.pbf -o beibu.osm.pbf`（osmium 安装：`winget install osmium` 或 pip 装 `osmium-tool`）
  - 备选：Overpass API 按 bbox 拉 GeoJSON（`https://overpass-api.de/api/interpreter`），无需下载整包，但单次请求量大时需分段
