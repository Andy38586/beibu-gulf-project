## 偏离与理由

1. **coverage 排除 `src/main.ts`**：进程启动引导不在测试链路（e2e 经 TestingModule 直建 app），与 backend 侧豁免 index.js 同口径。
2. **tsconfig include 追加 `vitest.config.ts`**：eslint typed-linting 的 project 服务要求被 lint 文件在 project 内。
3. **cruise 仅落 DB 收口一条规则**：原计划另加"feature 模块间禁止深引用"规则，但 dependency-cruiser 的 from/to 是独立正则，不支持跨正则反向引用（`\1`），写出来是假守护（比没有守护更危险）——撤回，该项由专项6 指标 8.2 检查方法人工执行。
4. **补装 `@types/express`**：controller 注入 Response 类型需要（首轮 build 暴露，即时修复）。
5. **`npm run dev:nest`（PID 38596）未停**：watch 模式常驻 3100。沙箱限制本会话无法 kill 进程（两次尝试均被拦截）；watch 模式恰好为 T1.2 提供自动重载。会话结束/用户裁决时处理。

## 问题与测试固化

- 首轮 coverage branches 0% < 50%：main.ts 未被测试覆盖且分支占比 100% → 偏离 1 排除；复测 coverage 100% 全绿。
