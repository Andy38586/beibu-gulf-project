## 做了什么

- `src/infra/db/`：
  - `db.config.ts`——`parseDbConfig(env)` 纯函数，默认值对齐 docker-compose.v3.yml（localhost:5432/postgres/postgres/v3_dev）；连接池参数显式（max 10 / idle 30s / connect 5s）；非法端口回退 5432。
  - `db.service.ts`——`DbService`（@Injectable）持唯一 `pg.Pool`，暴露 `query()`；`onModuleDestroy` 调 `pool.end()` 释放连接。
  - `db.module.ts`——`@Global()` 模块，根模块 import 一次全应用可注入。
- `/nest/health/ready`：SELECT 1 探活；库不可达 → 503 `{"status":"degraded","checks":{"db":false}}`（裸 JSON 形状对齐老 Express readinessHandler）。
- 依赖：`pg` + `@types/pg`。
- 测试：`test/db.config.spec.ts` 4 用例（默认值/覆盖/非法端口/池参数）；`health.e2e-spec.ts` 增库不可达路径（PG_PORT=1 指向必然拒绝端口，不依赖 Docker 状态）。
