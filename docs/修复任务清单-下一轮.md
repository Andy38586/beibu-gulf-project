## 阶段一：测试有效性前置修复（必须最先，预计 10 分钟）

**背景**：这两处恒真断言藏在 `V3_INTEGRATION_DB` 门控区，CI 恒跳过所以从未暴露。阶段三 C4 会激活真库测试，**不先修掉激活的就是假绿**。

- [ ] **T1-1** `backend/test/plans.repository.spec.ts:87`
  - 现状：`expect(saved[0].savedAt).not.toBe((once as ...).savedXiaoqu)` —— 拿时间戳与**数组**比较，恒真。
  - 修法：先读上下文确定用例意图（应为"更新后 savedAt 已刷新"），改为与更新前的 savedAt 值比较，或与 `once.savedXiaoqu[0].savedAt` 比较。修完后断言必须在"行为正确时通过、行为错误时失败"。

- [ ] **T1-2** `backend/test/spatial.repository.spec.ts:342`
  - 现状：`expect(samplePoints(20).filter(p => spatial && p.lng > 0).length).toBeGreaterThan(0)` —— 与被测逻辑无关的凑数断言。
  - 修法：直接删除该断言（真断言在下一行的 `booleanPointInPolygon`），不要用新的凑数断言替代。

**验证**：`npm test --prefix backend`（门控套件会跳过，确认语法/类型不破即可）；若本地有 PostGIS（`docker compose -f docker-compose.v3.yml up -d`），export `V3_INTEGRATION_DB=1` 后全量跑一次，记录结果。
