## 三、管线与复跑

### 3.1 链路的输入输出

```
tmp-pinglu/data/
  dem_corridor.hdr / .bin        ← 走廊 DEM（ENVI BSQ float32，4619×3198，1 arcsec，GLO-30 裁切）
  terrain_final.npy              ← ★ 地形输入（s2 产出；2026-09-27 已重建，见 §四 D-F）
  canal_centerline.json          ← 中线（2376 点 / 118.8 km）+ 沿线地形高程 + 设计水位
  src/{beibu-coastline,beibu-water}.geojson, gl30_dem_4326.tif
  sea_mask.npy                   ← s2 产出（★ 曾是坏的，99.8% 判海；见 §四 D-F）
tmp-pinglu/scripts/
  s1_dem.py     DEM 镶嵌
  s2_route.py   中线重建 + 海陆分离
  s3_build.py   ★ 在 Blender 内建模 + 导出 3D Tiles（唯一需要 Blender 的一步）
  _bm921_lib.py 9/21 构件库逐字复制   hub_bim921.py 适配器（只实现了 madao）
```

## 五、陷阱（都已踩过）

1. **批处理必须带错误计数**：`>/dev/null` 会"在旧产物上验收通过"。跑批要看 `EXIT=0` 且**日志有内容**；
   日志 0 字节 = 卡住，别以为是"跑得快"。
2. **Blender 的 stdout 会缓冲**（默认 4–8 KB 一块）⇒ 调试时用 `PYTHONUNBUFFERED=1`，否则看不出卡在哪。
3. **「瓦片纯白」是误判**：`globe.show=false` 但 `skyAtmosphere` 开着时，大气会在地球位置铺出纯白
   （实测 `(255,255,255)` 占屏 **52.7%**）。把 `scene.backgroundColor` 设成洋红哨兵即可验证：
   整屏洋红 = 除了大气什么都没画，**不是顶点色问题**。顶点色 `COLOR_0` 实测 63/63 正常（枢纽 34 色、地形绿系）。
4. **地球会吃掉瓦片**：走廊南段（青年—入海口）地表只有 0~20 m，与 h=0 的地球椭球面 z-fighting，地球胜出后
   整屏只剩 `#0d2338`。`globe.depthTestAgainstTerrain=true` **只会更糟**（几乎全被盖住）。
   ⇒ viewer 必须 `globe.show=false` **且** `skyAtmosphere.show=false` **且** `skyBox.show=false`。
5. **全览不能用固定机位**：地形有起伏后，固定「高度 + heading/pitch」会把视锥甩到走廊外（实测整屏纯黑、
   `cmds=13` 却什么都看不到）。全览一律 `viewer.zoomTo(tileset)`。
6. **`verify_tiles_geo.py` 必须解码真实顶点**，不能用 accessor 的 min/max —— 逐顶点椭球降落之后，
   局部包围盒角点不对应任何真实位置。
7. **`np.interp` 会在有效区间外按端点值外推** ⇒ 用「逐列海岸线」判海时必须把判定限制在有海岸线的列区间内，
   否则会把内陆判成海。
8. **Blender glTF 导入的轴**：glTF Y-up → Blender (x, −z, y)；Blender 里 **Z 是竖向**。
9. **9/21 包的 60 m 竖向错位**：`bake_wgs84.py` 根节点没减 bulge、子节点减了 ⇒ `*-low` 与 z 瓦片差 60 m。
   别拿它的 `cy` 当绝对高程；横向 `size_x/size_z` 可信。
10. **`tiles3dGroups` 会丢 child**（D-C）：补 `extras` 后要**重新数一遍分组后的 tileset**，别只看总数。
11. **agent-browser 在本沙箱起不来**（`open` 直接 SIGTERM）。用 `.local/926-rebake/shots/cdp_multi.mjs`
    （CDP + Edge），先 `unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY`。
12. **`/tmp` 不跨调用持久**；Bash 里 `node -e` 会炸正则 ⇒ 写脚本文件。
13. **后台起静态服务要用常驻方式**：`(nohup ... &)` 在 Bash 调用返回后会被回收，页面变成"拒绝连接"。
14. **`camera.lookAt` 在近垂直俯角（pitch ≤ −88°）会机位退化**：整屏纯黑或只剩 Cesium 加载转圈，
    **不是数据/瓦片问题**。要俯视就用 `camera.flyTo` + 明确的 `destination`/`orientation`。
15. **`publish_tiles.py` 原来 `rmtree` 目标瓦片目录会被安全护栏拦下**（仓库对 >50 个文件的批量删除要确认），
    被拦后**静默跳过拷贝、留下旧瓦片**（本轮踩到：`tiles-v2` 停在 20:47 而那轮产物是 21:04）。
    改成 `copytree(src, dst, dirs_exist_ok=True)` 直接覆盖。发布后**必须核验 mtime**。
16. **看"枢纽 + 地形合并"的成品图走 Blender**（`.local/926-rebake/render_madao.py` 从
    `pinglu-canal.blend` 渲染 WORKBENCH 顶点色），别只依赖 Cesium viewer —— 它有 D-I 的近景空洞。
    Blender 渲染 4 个机位只要 ~10 秒。
