## 三、修复问题清单（根因链，每条已验证）

### 3.1 3D 前端黑屏/无地形/竖条纹——四层叠加根因

1. **static 托管 404**：Express 退役时 express.static 职责未随迁（T6.3 漏项）→ 修：main.ts 补挂。
2. **.terrain 无 Content-Encoding**：CTB 瓦片本身是 gzip 流，老 Express/nginx 的特判迁移丢失 → 修：`/static/terrain` 专用流式中间件（express.static setHeaders 组合并发下偶发 500，实测后绕开）。
3. **layer.json format 错误**：声明 heightmap-1.0 但 CTB 实产 quantized-mesh 且头布局异常——**这套瓦片从未在 Cesium 渲染成功**（8-10 生产"无起伏"复盘即其症状：海面全 0 瓦片恰好解析成平地）。
4. **y 轴语义错位**：CTB 树 TMS（y=0 南）vs Cesium slippy（y=0 北），海面零瓦片错位不可见故漏检。

**终解**：放弃修坏数据，`tools/dem-pipeline/07-heightmap-reslice.py` 按 Cesium 官方规范重切 heightmap-1.0（65×65 uint16 = (h+1000)×5 + childTileMask 按真实瓦片树 + waterMask；输入 UTM 填洼版经 WarpedVRT 重投影）。Edge 无头复测：渲染/解码错误 0，底图/海面/标签全渲染。

### 4.2 ref 反复丢失（一天 11+ 次）与破局

- **现象**：每次 commit 后 `refs/heads/experiment/v3-backend-migration` 随机消失（有时目录整体消失）；恢复后下次 commit 再丢。
- **已排除**：gc/maintenance（auto=0 配置都在）、husky hooks、实时删除者（监控期手写 ref 存活——删除是事件驱动/间歇的）。
- **实锤**：删除者**精准针对 `refs/heads/experiment/` 子目录**（packed-refs/main/其他目录均不动；改名实验：重建该名 1 秒内即被删，此刻仍实时活跃）。
- **破局**：**分支改名 `v3-migration`**（根目录下，不建子目录）→ ref 彻底稳定。删除者身份未定位（WorkBuddy 桌面 6 进程嫌疑最大），procmon 过滤 `refs/heads/experiment` 可考古。
- **防御铁律**：① ref 文件必须写**完整 40 位哈希**（短哈希 git 拒解析 → unborn）；② 恢复脚本**禁止变量回显写 ref**（空值事故根源）——先 `git cat-file -t` 验对象，字面量写入，写后 `git rev-parse HEAD` 断言；③ 丢失后**从 reflog 恢复**：`NEW=$(awk 'END{print $2}' .git/logs/refs/heads/<分支>)`。
