## §3 结论（每条带作废条件）

1. **事实覆盖几乎等效**：T1 饱和、T2–T4 持平——迁移对事实是保真的，不是覆盖不足。
2. **方差小的原因**：任务饱和（两套材料同一事实源）+ 单点低显著项抽样噪声；
   不是「文档过拟合」的假绿——但 T1 只测到按清单型任务的上限，测不到程序性任务。
3. **新体系的真实优势 = 压缩与一致性**：token −24.5%、token 标准差约 −40%、
   部署口径与实现对齐（K4 §7.2）；旧体系优势 = 程序完整与历史链条。
4. **新体系的真实缺口 = C 类程序**：KP-017（旧 AGENTS §十一「审查窗作业标准」）是
   kp-map 里唯一 `authority=old` 的条目，登记目标 STD 不含六节清单；实验里唯一输的题
   正是它——「唯一没迁的条款，正好是唯一输的题」。补跑证明：按矩阵正路（STD+S1）
   拿不到节名，只有绕进生成器源码才能拼回。
5. **边界外推**：程序/格式/交付形态类任务，旧件可能更完整；现行口径/效率/一致性类任务，
   新体系稳赢。在 KP-017 补迁与旧件退役裁决之前，不应把旧 AGENTS 当死档处理。
6. **作废条件**：模型/effort/材料集合/执行体任一变化 ⇒ 本数据整体失效；边界题 n=1 只作指示、
   不作统计；T1 标记法未覆盖语义等价改写（人工抽检仅上述反例扫描）。
7. **未证**：单次调用成本与限流影响未测；`.local/ab/` 原始输出为 gitignored 易失件，
   跨机器复跑前该证据不可用；T5 补跑的 7.5/8 为人工折算，非标记法产物。
