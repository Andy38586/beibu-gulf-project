## 一、正式口径声明

1. **基线 = 无运河反事实**：吞吐量模型产物（`throughput_model.json` / `container_model.json`）
   不建模运河增量；`model_info.canal_assumption` 随本定稿改写（同笔提交）。
2. **运河增量 = 情景叠加层**：`design`（保守·初步设计）/ `median`（基准·中位）/
   `induced`（乐观·含诱增）三档，由 `scenario.service.ts` 纯函数叠加，仅作用于预测段，
   历史段与 reliability 不动；前端可切换（仅 cargo 指标）。
3. **默认分摊 = 2022 年现状吞吐量结构**（钦 0.47 / 防 0.41 / 北 0.12，和恒 1，spec 守卫）；
   中性可辩护假设（[罗淳2024] §2.6）。
4. **倾斜不进默认值**：钦州倾斜方案（+5pp / +10pp，防/北按比例再归一）只以区间呈现
   （见 §三），默认分摊不变——拍任何点值进默认都不可辩护。

**读法**：三类敏感轴（总量口径缩放、江海联运口径缩放、港域分摊倾斜）中，前两者对增量
严格线性、分摊按份额线性；钦州倾斜 ±10pp 对其 2035 增量的影响幅度约 ±21%（三档一致），
方向与幅度可直接由本表区间呈现，不再需要新算例。

## 四、口径纪律（论文正文引用时遵守）

- 引运河增量一律**三档并列**（design/median/induced），不允许只引乐观档；
- 分摊数字引用默认结构，倾斜敏感性以本文件 §三 区间表述；
- 基线与情景两个口径并列可回放（前端切换 / 后端 `scenario` 参数），不得用情景值冒充基线预测值；
- 区间上下界（lower/upper）是**基线回测误差分位校准**（P0-3，名义 80%），与运河情景档位
  是两个正交维度，不得混引。

## 六、失效条件

1. `scenario.constants.ts` 锚点或分摊口径变更 ⇒ §二/§三 全部重算，本文件另开新带日期快照；
2. 官方月度数据（cargo.json / container.json）追加 ⇒ 基线重跑，情景叠加层不受影响但引用
   时点需更新；
3. 倾斜方案获得用户供数（钦州倾斜的权威依据）⇒ §三 从「敏感性区间」升级为「实证区间」，
   本文件随之改写；
4. 前端/接口新增运河相关的第四档或改档位语义 ⇒ 一并重述。
