## 三 · 🔴 两条必须知道的发现

### 1. `run-all.test.mjs` 有一条**预存红**（非本窗引入）

`ciTriggerProblems(wf,'guard:mutation',jobBlockOf)` 在**真 ci.yml** 上报 1 个问题。
**A/B 验证**：把 `ci.yml` 换回 HEAD 版再跑，红得一模一样 ⇒ 与本窗改动无关。

**为什么这条重要**：它一直以 `guard:mutation` 的 `run-all: error — 基线非绿（status=1）` 形态出现，
**看起来像环境问题而不是真红**，于是长期无人查。
⇒ 这是「**从未红过的门禁 = 不存在**」的镜像：**一直红着的门禁，同样等于不存在**（已失去区分能力）。
**须单独开账**：定性已做，**定因未做**。

### 2. commitlint「subject 忌大写开头」这条坑，本窗命中 **4 次**

且**全都是同一种形态：技术名词开头**——
`K1 新增 H6…` → `ProfilePage …` / `LoginPanel …` → `OLRenderer …` → `WEIGHT_KEYS …`，全部被拦。

⇒ **唯一稳的写法是中文动词起头**。落盘脚本改完 subject 后，务必跑一次：

```bash
for f in .local/wb00-落盘-*.sh; do grep -h -oE "^(chore|fix|feat|refactor|docs|test|style|perf|ci|build): .*" "$f"; done \
  | awk '{sub(/^[a-z]+: /,""); if (substr($0,1,1) ~ /[A-Z]/) print "⚠️ "$0}'
```
