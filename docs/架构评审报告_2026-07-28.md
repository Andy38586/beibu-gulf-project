## 1. 架构健康度评分
**62 / 100**。分层骨架健康、解耦根基扎实，但契约纪律回退（A04/A05/硬编码色）与稳定性债务（D06/D01/B01）未消；不建议推倒架构，需补执行纪律 + 修数据层。

## 2. 最严重契约违规 / 稳定性问题
1. **A05 visualization 反向依赖 business（违反分层 §2.3 Rule 3）**：`src/visualization/charts/composables/useRadarChart.js:19`、`RadarScoreTooltip.vue:11` 直接 import `@/business/site-selection` 的 facilityConfig/useFacilities。→ 抽 FACILITY_CONFIG 到 shared/constants，切断反向边。
2. **D06 引擎切换图层数据丢失（稳定性 P1）**：`src/core/map/renderers/MapRenderer.js:123-133` 的 exportState 仅存 `{visible}` 与 camera，不存数据源；importState 仅恢复可见性。→ exportState 同步序列化图层数据源/参数。
3. **A04 裸 fetch 绕过 useApiRequest（契约 §4）**：`src/services/mapDataService.ts:20`、`core/map/composables/useBoundaryLayer.js:42`、`services/adapters/forecastAdapter.ts:15,24`、`floodAdapter.ts:34` 裸 fetch。→ 统一改走 useApiRequest。
4. **SiteSelectionPage 缺 pointer-events 复位（GCS 四铁律 §2）**：`src/business/site-selection/SiteSelectionPage.vue:375` 设 `pointer-events:none` 但缺 `:deep(.gcs-panel){pointer-events:auto}`（另两页有）。→ 面板不可交互，补该规则。
5. **硬编码十六进制色（契约 §3）**：business 层 `flood-analysis/FloodAnalysisPage.vue:372,381-388`、`site-selection/composables/facilityConfig.js:10-35`、`useAnalysisLayer.js:64,71`、`WaterLevelProfilePanel.vue:237,241,255,260` 及 visualization `useChartBase.js:24`、`useRadarChart.js:101-124` 硬编码色，未用 `var(--gcs-*)`。→ 提常量到 CSS 变量。
