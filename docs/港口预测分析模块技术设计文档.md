```
Home Layout（Layout Base）
    ↓

    ├── 复用图层管理机制
```

**关键约束**：

- ❌ 不主动进行 OL/Cesium 切换（Forecast 基于 2D 即可）
- ❌ 不重新设计地图系统

## 二、时间轴设计（核心）

### 2.1 时间状态管理

#### 2.1.1 状态存储位置

```typescript
// src/stores/forecastStore.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useForecastStore = defineStore('forecast', () => {
  // ==================== 时间状态 ====================
  /** 当前时间（YYYY-MM 格式） */
  const currentTime = ref('2025-12')
  
  /** 时间范围 */
  const timeRange = ref({
    start: '2018-01',  // 历史数据起点
    end: '2035-12',    // 预测数据终点
    current: '2025-12' // 当前时间（数据截止点）
  })
  
  /** 时间粒度：month | year */
  const timeGranularity = ref<'month' | 'year'>('month')
  
  /** 是否正在播放时间动画 */
  const isPlaying = ref(false)
  
  /** 播放速度（毫秒/帧） */
  const playSpeed = ref(500)
  
  // ==================== 指标状态 ====================
  /** 当前激活的预测指标 */
  const activeIndicator = ref<'throughput' | 'berth' | 'traffic' | 'pressure' | 'development'>('throughput')
  
  /** 当前激活的预测图层 */
  const activeForecastLayer = ref<string | null>(null)
  
  // ==================== 数据状态 ====================
  /** 预测数据缓存（按时间索引） */
  const dataCache = ref<Map<string, any>>(new Map())
  
  /** 当前时间戳的数据 */
  const currentData = computed(() => {
    return dataCache.value.get(currentTime.value) || null
  })
  
  // ==================== Actions ====================
  /**
   * 设置当前时间
   * @param time - YYYY-MM 或 YYYY 格式
   */
  function setCurrentTime(time: string) {
    currentTime.value = time
  }
  
  /**
   * 设置时间粒度
   */
  function setTimeGranularity(granularity: 'month' | 'year') {
    timeGranularity.value = granularity
  }
  
  /**
   * 设置激活的预测指标
   */
  function setActiveIndicator(indicator: typeof activeIndicator.value) {
    activeIndicator.value = indicator
  }
  
  /**
   * 缓存数据
   */
  function cacheData(time: string, data: any) {
    dataCache.value.set(time, data)
  }
  
  /**
   * 清除缓存
   */
  function clearCache() {
    dataCache.value.clear()
  }
  
  /**
   * 重置所有状态
   */
  function reset() {
    currentTime.value = '2025-12'
    activeIndicator.value = 'throughput'
    activeForecastLayer.value = null
    isPlaying.value = false
    clearCache()
  }
  
  return {
    // 时间状态
    currentTime,
    timeRange,
    timeGranularity,
    isPlaying,
    playSpeed,
    
    // 指标状态
    activeIndicator,
    activeForecastLayer,
    
    // 数据状态
    dataCache,
    currentData,
    
    // Actions
    setCurrentTime,
    setTimeGranularity,
    setActiveIndicator,
    cacheData,
    clearCache,
    reset
  }
})
```

#### 2.1.2 时间状态流转

```
用户拖动时间滑块
    ↓
ForecastTimeline 组件触发 update:currentTime
    ↓
forecastStore.setCurrentTime(time)
    ↓
触发响应式更新：
    ├── ForecastMap 监听 currentTime → 请求新时间的图层数据 → 更新地图图层
    ├── ForecastChart（折线图）监听 currentTime → 移动时间指示线
    ├── ForecastChart（柱状图）监听 currentTime → 更新当前年份港口对比
    └── ForecastPanel 监听 currentTime → 更新指标数值
```

#### 2.1.3 组件监听方式

```vue
<!-- ForecastMap.vue -->
<script setup lang="ts">
import { watch } from 'vue'
import { useForecastStore } from '@/stores/forecastStore'

const forecastStore = useForecastStore()

// 监听时间变化
watch(
  () => forecastStore.currentTime,
  async (newTime) => {
    // 1. 检查缓存
    if (forecastStore.dataCache.has(newTime)) {
      updateMapLayer(forecastStore.dataCache.get(newTime))
      return
    }
    
    // 2. 请求数据
    const data = await fetchForecastData(newTime)
    
    // 3. 缓存数据
    forecastStore.cacheData(newTime, data)
    
    // 4. 更新地图图层
    updateMapLayer(data)
  }
)

// 监听指标变化
watch(
  () => forecastStore.activeIndicator,
  (newIndicator) => {
    // 切换图层类型
    switchMapLayerType(newIndicator)
  }
)
</script>
```

### 2.2 时间轴组件设计

#### 2.2.1 组件结构

```vue
<!-- src/business/forecast/components/ForecastTimeline.vue -->
<template>
  <div class="forecast-timeline panel-frosted">
    <!-- 时间范围显示 -->
    <div class="timeline-header">
      <span class="start-year">{{ timeRange.start }}</span>
      <span class="current-time">{{ currentTime }}</span>
      <span class="end-year">{{ timeRange.end }}</span>
    </div>
    
    <!-- 时间滑块 -->
    <div class="timeline-slider">
      <input
        type="range"
        :min="0"
        :max="maxSteps"
        :value="currentStep"
        @input="onSliderInput"
        class="time-range"
      />
      
      <!-- 时间刻度 -->
      <div class="time-ticks">
        <div
          v-for="tick in timeTicks"
          :key="tick.time"
          class="tick"
          :class="{ active: tick.time === currentTime }"
        >
          {{ tick.label }}
        </div>
      </div>
    </div>
    
    <!-- 播放控制 -->
    <div class="timeline-controls">
      <button @click="togglePlay" class="control-btn">
        {{ isPlaying ? '⏸️' : '▶️' }}
      </button>
      
      <select v-model="timeGranularity" @change="onGranularityChange">
        <option value="month">月度</option>
        <option value="year">年度</option>
      </select>
      
      <button @click="resetTime" class="control-btn">
        🔄
      </button>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import { useForecastStore } from '@/stores/forecastStore'

const forecastStore = useForecastStore()

const currentTime = computed(() => forecastStore.currentTime)
const timeRange = computed(() => forecastStore.timeRange)
const timeGranularity = computed({
  get: () => forecastStore.timeGranularity,
  set: (val) => forecastStore.setTimeGranularity(val)
})
const isPlaying = computed(() => forecastStore.isPlaying)

// 计算总步数
const maxSteps = computed(() => {
  if (timeGranularity.value === 'year') {
    return 2035 - 2018
  }
  // 月度：从 2018-01 到 2035-12
  return (2035 - 2018 + 1) * 12
})

// 当前步数
const currentStep = computed(() => {
  const [year, month] = currentTime.value.split('-').map(Number)
  if (timeGranularity.value === 'year') {
    return year - 2018
  }
  return (year - 2018) * 12 + (month - 1)
})

// 时间刻度
const timeTicks = computed(() => {
  const ticks = []
  const step = timeGranularity.value === 'year' ? 5 : 12
  for (let i = 0; i <= maxSteps.value; i += step) {
    const time = stepToTime(i)
    ticks.push({
      time,
      label: timeGranularity.value === 'year' ? time : time.split('-')[0]
    })
  }
  return ticks
})

// 步数转时间
function stepToTime(step: number): string {
  if (timeGranularity.value === 'year') {
    return String(2018 + step)
  }
  const year = 2018 + Math.floor(step / 12)
  const month = (step % 12) + 1
  return `${year}-${String(month).padStart(2, '0')}`
}

// 滑块输入
function onSliderInput(e: Event) {
  const step = Number((e.target as HTMLInputElement).value)
  const time = stepToTime(step)
  forecastStore.setCurrentTime(time)
}

// 切换播放
function togglePlay() {
  forecastStore.isPlaying = !forecastStore.isPlaying
  if (forecastStore.isPlaying) {
    startPlayback()
  }
}

// 开始播放
function startPlayback() {
  const interval = setInterval(() => {
    if (!forecastStore.isPlaying) {
      clearInterval(interval)
      return
    }
    
    const currentStep = currentStep.value
    if (currentStep >= maxSteps.value) {
      forecastStore.isPlaying = false
      clearInterval(interval)
      return
    }
    
    const nextTime = stepToTime(currentStep + 1)
    forecastStore.setCurrentTime(nextTime)
  }, forecastStore.playSpeed)
}

// 切换粒度
function onGranularityChange() {
  // 保持当前时间，只改变显示粒度
}

// 重置时间
function resetTime() {
  forecastStore.setCurrentTime('2025-12')
}
</script>
```

## 三、预测指标设计

### 3.1 指标定义

| 指标名称 | 业务意义 | 数据来源假设 | 可视化方式 | 对应地图图层 |
|---------|---------|-------------|-----------|-------------|
| **吞吐量预测** | 预测港口货物吞吐量，反映港口规模发展 | 历史吞吐量数据 + 经济增长率 + 政策规划 | 热力图（颜色深浅） | `throughput-heatmap` |
| **泊位利用率预测** | 预测泊位使用效率，反映港口服务能力 | 历史泊位数据 + 船舶流量 + 泊位数量 | 颜色渐变（绿→黄→红） | `berth-utilization` |
| **船舶流量预测** | 预测进出港船舶数量，反映港口活跃度 | 历史船舶AIS数据 + 航线规划 | 流线图（箭头密度） | `ship-traffic-flow` |
| **港口物流压力指数** | 综合评估港口物流负荷，反映拥堵风险 | 吞吐量 + 泊位利用率 + 集疏运能力 | 等值线图 | `logistics-pressure` |
| **港口发展指数** | 综合评估港口发展潜力，反映未来竞争力 | 吞吐量 + 泊位利用率 + 区域经济 + 政策支持 | 区域填充图 | `development-index` |

### 3.2 指标详细设计

#### 3.2.1 吞吐量预测（Throughput）

**业务意义**：
- 预测未来港口货物吞吐量（万吨）
- 帮助决策者了解港口规模发展趋势
- 为基础设施建设提供数据支撑

**数据来源假设**：
```json
{
  "historical": "2018-2025年实际吞吐量数据（月度）",
  "factors": {
    "gdp_growth": "区域GDP增长率",
    "trade_volume": "区域贸易总额",
    "policy_support": "政策支持系数（0-1）"
  }
}
```

**可视化方式**：
- **地图**：热力图，颜色深浅表示吞吐量大小
- **折线图**：时间趋势线，显示历史+预测
- **柱状图**：当前年份各港口对比

**地图图层设计**：
```javascript
// 图层名称：throughput-heatmap
// 图层类型：Heatmap Layer（OpenLayers）
// 数据来源：forecast/throughput.json

```

#### 3.2.2 泊位利用率预测（Berth Utilization）

**业务意义**：
- 预测泊位使用效率（%）
- 识别瓶颈泊位
- 优化泊位资源配置

**数据来源假设**：

**可视化方式**：
- **地图**：颜色渐变，绿（<50%）→ 黄（50-80%）→ 红（>80%）
- **折线图**：利用率时间趋势

#### 3.2.4 港口物流压力指数（Logistics Pressure）

**业务意义**：
- 综合评估港口物流负荷（0-100）
- 识别拥堵风险
- 为疏港交通规划提供依据

**数据来源假设**：
```json
{
  "throughput": "吞吐量",
  "berth_utilization": "泊位利用率",
  "road_capacity": "集疏运道路容量",
  "rail_capacity": "铁路集疏运能力"
}
```

**计算公式**：
```javascript
pressureIndex = (
  throughput * 0.4 +
  berthUtilization * 0.3 +
  roadCongestion * 0.2 +
  railCongestion * 0.1
)
```

**可视化方式**：
- **地图**：等值线图，显示压力分布
- **折线图**：压力指数时间趋势
- **预警**：压力指数 > 80 时显示预警标识

**地图图层设计**：
```javascript

//   60-80 → #fa8c16    // 橙色（高压）
//   80-100 → #f5222d   // 红色（极高压）
```

#### 3.2.5 港口发展指数（Development Index）

**业务意义**：
- 综合评估港口发展潜力（0-100）
- 反映港口未来竞争力
- 为投资决策提供参考

**数据来源假设**：
```json
{
  "throughput_growth": "吞吐量增长率",

  "regional_economy": "区域经济指标",
  "policy_support": "政策支持力度"
```

**计算公式**：
```javascript
developmentIndex = (
```

**可视化方式**：
- **地图**：区域填充图，按港区填充颜色
- **折线图**：发展指数时间趋势
- **雷达图**：多维度对比（可选）

**地图图层设计**：

#### 5.3.3 服务层实现

```javascript
// server/services/forecastService.js
const path = require('path')
const fs = require('fs').promises

const DATA_DIR = path.join(__dirname, '../../public/data/forecast')

/**
 * 读取 JSON 数据文件
 */
async function readDataFile(filename) {
  const filePath = path.join(DATA_DIR, filename)
  const content = await fs.readFile(filePath, 'utf-8')
  return JSON.parse(content)
}

/**
 * 获取地图图层数据
 */
exports.getMapData = async (indicator, time) => {
  const data = await readDataFile(`${indicator}.json`)
  
  // 提取指定时间点的数据
  const features = []
  for (const portId in data.data) {
    const portData = data.data[portId]
    const spatial = portData.spatial
    
    if (spatial && spatial.features) {
      spatial.features.forEach(feature => {
        const value = feature.properties.values[time]
        if (value !== undefined) {
          features.push({
            type: 'Feature',
            geometry: feature.geometry,
            properties: {
              portId: feature.properties.portId,
              portName: feature.properties.portName,
              value: value,
              confidence: portData.forecast.find(f => f.time === time)?.confidence || 1
            }
          })
        }
      })
    }
  }
  
  return {
    indicator: data.indicator,
    unit: data.unit,
    time: time,
    type: 'FeatureCollection',
    features: features
  }
}

/**
 * 获取港口数据
 */
exports.getPortData = async (portId, indicator, start, end) => {
  const indicators = indicator ? [indicator] : ['throughput', 'berth', 'traffic', 'pressure', 'development']
  
  const result = {
    portId: portId,
    portName: '',
    indicators: {}
  }
  
  for (const ind of indicators) {
    const data = await readDataFile(`${ind}.json`)
    const portData = data.data[portId]
    
    if (!result.portName && portData?.spatial?.features?.[0]) {
      result.portName = portData.spatial.features[0].properties.portName
    }
    
    if (portData) {
      let historical = portData.historical
      let forecast = portData.forecast
      
      // 时间过滤
      if (start) {
        historical = historical.filter(d => d.time >= start)
        forecast = forecast.filter(d => d.time >= start)
      }
      if (end) {
        historical = historical.filter(d => d.time <= end)
        forecast = forecast.filter(d => d.time <= end)
      }
      
      result.indicators[ind] = {
        unit: data.unit,
        historical: historical,
        forecast: forecast
      }
    }
  }
  
  return result
}

/**
 * 获取指标数据
 */
exports.getIndicatorData = async (type, time, portId) => {
  const data = await readDataFile(`${type}.json`)
  
  const result = {
    indicator: data.indicator,
    unit: data.unit,
    ports: {}
  }
  
  const ports = portId ? [portId] : Object.keys(data.data)
  
  for (const pid of ports) {
    const portData = data.data[pid]
    if (portData) {
      const portName = portData.spatial?.features?.[0]?.properties?.portName || pid
      
      let value = null
      if (time) {
        const histPoint = portData.historical.find(d => d.time === time)
        const forePoint = portData.forecast.find(d => d.time === time)
        const point = histPoint || forePoint
        value = point?.value || null
      }
      
      result.ports[pid] = {
        portName: portName,
        value: value,
        historical: portData.historical,
        forecast: portData.forecast
      }
    }
  }
  
  return result
}

/**
 * 获取时间序列数据
 */
exports.getTimeSeriesData = async (indicator, portId, start, end, granularity) => {
  const data = await readDataFile(`${indicator}.json`)
  
  const ports = portId ? [portId] : Object.keys(data.data)
  
  const series = []
  for (const pid of ports) {
    const portData = data.data[pid]
    if (portData) {
      const portName = portData.spatial?.features?.[0]?.properties?.portName || pid
      
      let allData = [...portData.historical, ...portData.forecast]
      
      // 时间过滤
      if (start) {
        allData = allData.filter(d => d.time >= start)
      }
      if (end) {
        allData = allData.filter(d => d.time <= end)
      }
      
      // 粒度处理
      if (granularity === 'year') {
        const yearlyData = {}
        allData.forEach(d => {
          const year = d.time.split('-')[0]
          if (!yearlyData[year]) {
            yearlyData[year] = { time: year, value: 0, count: 0, type: d.type }
          }
          yearlyData[year].value += d.value
          yearlyData[year].count++
        })
        allData = Object.values(yearlyData).map(d => ({
          time: d.time,
          value: Math.round(d.value / d.count),
          type: d.type
        }))
      }
      
      series.push({
        portId: pid,
        portName: portName,
        data: allData
      })
    }
  }
  
  return {
    indicator: data.indicator,
    unit: data.unit,
    granularity: granularity || 'month',
    series: series
  }
}
```

```javascript
        let color = '#52c41a' // 绿色
        if (value > 80) color = '#f5222d' // 红色
        else if (value > 50) color = '#faad14' // 黄色
        
        return new Style({
          image: new CircleStyle({
            radius: 10,
            fill: new Fill({ color }),
            stroke: new Stroke({ color: 'white', width: 2 })
          })
        })
      }
    },
    traffic: {
      type: 'vector',
      style: (feature) => {
        const traffic = feature.get('traffic')
        return new Style({
          stroke: new Stroke({
            color: '#409eff',
            width: Math.max(2, traffic / 100)
          })
        })
      }
    },
    pressure: {
      type: 'vector',
      style: (feature) => {
        const value = feature.get('value')
        let color = '#52c41a'
        if (value > 80) color = '#f5222d'
        else if (value > 60) color = '#fa8c16'
        else if (value > 40) color = '#faad14'
        
        return new Style({
          fill: new Fill({ color: color + '80' }), // 半透明
          stroke: new Stroke({ color, width: 2 })
        })
      }
    },
    development: {
      type: 'vector',
      style: (feature) => {
        const value = feature.get('value')
        let color = '#52c41a'
        if (value > 80) color = '#722ed1'
        else if (value > 60) color = '#1890ff'
        else if (value > 40) color = '#faad14'
        
        return new Style({
          fill: new Fill({ color: color + '80' }),
          stroke: new Stroke({ color, width: 2 })
        })
      }
    }
  }
  
  // 创建图层
  function createLayer(indicator, geojson) {
    const config = layerConfigs[indicator]
    if (!config) return null
    
    const source = new VectorSource({
      features: new GeoJSON().readFeatures(geojson, {
        featureProjection: 'EPSG:3857'
      })
    })
    
    if (config.type === 'heatmap') {
      return new Heatmap({
        source,
        weight: 'value',
        ...config.style
      })
    } else {
      return new VectorLayer({
        source,
        style: config.style
      })
    }
  }
  
  // 更新图层
  async function updateLayer() {
    const indicator = forecastStore.activeIndicator
    const time = forecastStore.currentTime
    
    // 请求数据
    const response = await fetch(`/api/forecast/map?indicator=${indicator}&time=${time}`)
    const data = await response.json()
    
    // 移除旧图层
    if (currentLayer.value) {
      map.removeLayer(currentLayer.value)
    }
    
    // 创建新图层
    const layer = createLayer(indicator, data.data)
    if (layer) {
      map.addLayer(layer)
      currentLayer.value = layer
    }
  }
  
  // 监听变化
  watch(
    () => [forecastStore.activeIndicator, forecastStore.currentTime],
    () => {
      updateLayer()
    }
  )
  
  // 初始化
  updateLayer()
  
  // 清理
  onUnmounted(() => {
    if (currentLayer.value) {
      map.removeLayer(currentLayer.value)
    }
  })
  
  return {
    updateLayer
  }
}
```

## 十、性能设计

### 10.1 数据缓存策略

```typescript
// 前端缓存：按时间索引
const dataCache = ref<Map<string, any>>(new Map())

// 请求前检查缓存
async function fetchData(time: string) {
  if (dataCache.value.has(time)) {
    return dataCache.value.get(time)
  }
  
  const data = await request({ url: '/api/forecast/map', params: { time } })
  dataCache.value.set(time, data)
  return data
}
```

### 10.2 按需请求

- **不一次性加载所有时间数据**
- 每次只请求当前时间点的数据
- 预加载相邻时间点（可选）

```typescript
// 预加载策略
function preloadAdjacentTimes(currentTime: string) {
  const [year, month] = currentTime.split('-').map(Number)
  
  // 预加载前1个月和后1个月
  const prevTime = month === 1 
    ? `${year - 1}-12` 
    : `${year}-${String(month - 1).padStart(2, '0')}`
  const nextTime = month === 12 
    ? `${year + 1}-01` 
    : `${year}-${String(month + 1).padStart(2, '0')}`
  
  fetchData(prevTime)
  fetchData(nextTime)
}
```

### 10.3 图层优化

- **图层复用**：相同类型的图层不重复创建

### 10.4 图表优化

   - 反映港口吞吐量发展趋势

4. **折线图同步变化**
   - 时间指示线随滑块移动
   - 显示历史+预测趋势

5. **柱状图同步变化**
   - 显示当前年份三个港口对比
   - 随时间变化数据更新

6. **不同指标可以切换**
   - 点击指标按钮切换
   - 地图、图表同步更新
   - 展开二级控制面板

- **历史回顾**：2018-2025 实际数据
- **现状展示**：2025 当前状态
- **未来预测**：2026-2035 预测趋势
- **态势推演**：通过时间滑块动态展示发展过程

最终形成：**时间驱动 → 数据变化 → 可视化联动 → 用户感知未来趋势** 的完整闭环。
