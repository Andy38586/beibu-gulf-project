## 一、模块定位与架构关系

### 1.1 三大业务模块关系

```
Home（首页）          → 港口运行态势展示（当前状态）
SiteSelection（选址） → 空间决策分析（空间规划）
Forecast（预测分析）  → 时间趋势分析（未来预测）
```

三者共同形成：**当前状态 → 空间规划 → 未来预测** 的完整决策链。

### 1.2 架构继承关系

Forecast 作为业务路由，**严格继承 Home Layout（Layout Base）**，模式与 SiteSelectionPage、GCSAnalysisPage 完全一致：

```
App.vue
├── UnifiedMap（地图，全局挂载）
└── RouterView
    └── ForecastPage.vue（业务路由）
        └── <AppLayout>（继承 Layout Base）
            ├── #left slot → 折线图 + 柱状图
            └── #right slot → 指标面板 + 时间轴面板
```

**关键约束**：

- 复用 `AppLayout`（提供标题栏、城市按钮、底部导航）
- 复用 `UnifiedMap`（已在 App.vue 根级别挂载，不重复引入）
- 复用 `GcsPanel`（所有面板定位容器）
- 复用 `useLayerManager`（图层注册/切换）
- 复用 `LineChart`/`BarChart`（可视化资产）
- 引擎由 `route.meta.engine: '2d'` 自动决定，不手动切换

### 1.3 与现有业务路由的对比

| 维度   | SiteSelection         | GCSAnalysis      | Forecast             |

## 二、时间轴设计（核心）

### 2.1 时间状态管理

#### 2.1.1 状态存储位置

```javascript
// src/stores/forecastState.js
// 注意：使用 .js 文件，与 gcsStore.js / map.js / siteSelectionState.js 保持一致
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useForecastState = defineStore('forecast', () => {
  // ==================== 时间状态 ====================
  /** 当前时间（YYYY-MM 格式） */
  const currentTime = ref('2025-12')

  /** 时间范围 */
  const timeRange = ref({
    start: '2018-01', // 历史数据起点
    end: '2035-12', // 预测数据终点
    current: '2025-12', // 数据截止点
  })

  /** 时间粒度：month | year */
  const timeGranularity = ref('month')

  /** 是否正在播放时间动画 */
  const isPlaying = ref(false)

  /** 播放速度（毫秒/帧） */
  const playSpeed = ref(500)

  // ==================== 指标状态 ====================
  /** 当前激活的预测指标 */
  const activeIndicator = ref('throughput')

  /** 当前激活的预测图层 key */
  const activeForecastLayer = ref(null)

  // ==================== 数据状态 ====================
  /** 预测数据缓存（按时间索引） */
  const dataCache = ref(new Map())

  /** 当前时间戳的数据 */
  const currentData = computed(() => {
    return dataCache.value.get(currentTime.value) || null
  })

  // ==================== Actions ====================
  function setCurrentTime(time) {
    currentTime.value = time
  }

  function setTimeGranularity(granularity) {
    timeGranularity.value = granularity
  }

  function setActiveIndicator(indicator) {
    activeIndicator.value = indicator
  }

  function cacheData(time, data) {
    dataCache.value.set(time, data)
  }

  function clearCache() {
    dataCache.value.clear()
  }

  function reset() {
    currentTime.value = '2025-12'
    activeIndicator.value = 'throughput'
    activeForecastLayer.value = null
    isPlaying.value = false
    clearCache()
  }

  return {
    currentTime,
    timeRange,
    timeGranularity,
    isPlaying,
    playSpeed,
    activeIndicator,
    activeForecastLayer,
    dataCache,
    currentData,
    setCurrentTime,
    setTimeGranularity,
    setActiveIndicator,
    cacheData,
    clearCache,
    reset,
  }
})
```

#### 2.1.2 时间状态流转

```
用户拖动时间滑块
    ↓
ForecastTimeline 调用 forecastState.setCurrentTime(time)
    ↓
触发响应式更新：
    ├── useForecastLayer 监听 → 请求新时间图层数据 → 通过 renderer 更新地图
    ├── ForecastPage 监听 → 更新 LineChart 的 xData/series（时间指示线）
    ├── ForecastPage 监听 → 更新 BarChart 的 xData/series（港口对比）
    └── ForecastPanel 监听 → 更新当前数值显示
```

#### 2.1.3 组件监听方式

```javascript
// 在 ForecastPage.vue 中

const forecastState = useForecastState()
```

### 2.2 时间轴组件设计

时间轴作为 **右下 4x4 GcsPanel** 的内容，通过 AppLayout 的 `#right` slot 注入。

```vue
<!-- src/business/forecast/components/ForecastTimeline.vue -->
<script setup>
/**
 * ForecastTimeline - 全局时间控制器
 *
 * 职责：
 * 1. 提供时间滑块，控制 currentTime
 * 2. 提供播放/暂停控制
 * 3. 提供粒度切换（月度/年度）
 *
 * 放置在 AppLayout #right slot 的下方 GcsPanel（4x4）中
 */
import { computed } from 'vue'
import { useForecastState } from '@/stores/forecastState'

const forecastState = useForecastState()

const currentTime = computed(() => forecastState.currentTime)
const timeRange = computed(() => forecastState.timeRange)
const isPlaying = computed(() => forecastState.isPlaying)
const timeGranularity = computed({
  get: () => forecastState.timeGranularity,
  set: (val) => forecastState.setTimeGranularity(val),
})

// 计算总步数
const maxSteps = computed(() => {
  if (forecastState.timeGranularity === 'year') {
    return 2035 - 2018
  }
  return (2035 - 2018 + 1) * 12
})

// 当前步数
const currentStep = computed(() => {
  const parts = currentTime.value.split('-')
  const year = parseInt(parts[0])
  const month = parseInt(parts[1])
  if (forecastState.timeGranularity === 'year') {
    return year - 2018
  }
  return (year - 2018) * 12 + (month - 1)
})

// 步数转时间
function stepToTime(step) {
  if (forecastState.timeGranularity === 'year') {
    return String(2018 + step)
  }
  const year = 2018 + Math.floor(step / 12)
  const month = (step % 12) + 1
  return year + '-' + String(month).padStart(2, '0')
}

// 滑块输入
function onSliderInput(e) {
  const step = Number(e.target.value)
  forecastState.setCurrentTime(stepToTime(step))
}

// 播放/暂停
function togglePlay() {
  forecastState.isPlaying = !forecastState.isPlaying
  if (forecastState.isPlaying) {
    startPlayback()
  }
}

let playbackTimer = null

function startPlayback() {
  playbackTimer = setInterval(() => {
    if (!forecastState.isPlaying) {
      clearInterval(playbackTimer)
      return
    }
    const step = currentStep.value
    if (step >= maxSteps.value) {
      forecastState.isPlaying = false
      clearInterval(playbackTimer)
      return
    }
    forecastState.setCurrentTime(stepToTime(step + 1))
  }, forecastState.playSpeed)
}

function resetTime() {
  forecastState.setCurrentTime('2025-12')
}
</script>

<template>

      <span>{{ timeRange.start }}</span>
      <span class="current-time">{{ currentTime }}</span>
      <span>{{ timeRange.end }}</span>
    </div>

    <!-- 时间滑块 -->
    <div class="timeline-slider">
      <input
        type="range"
        :min="0"
        :max="maxSteps"
        :value="currentStep"
        @input="onSliderInput"
        class="time-range"
      />
    </div>

    <!-- 时间刻度 -->
    <div class="time-ticks">
      <span>2018</span>
      <span>2022</span>
      <span>2025</span>
      <span>2030</span>
      <span>2035</span>
    </div>

    <!-- 控制按钮 -->
    <div class="timeline-controls">
      <button @click="togglePlay" class="ctrl-btn">
        {{ isPlaying ? '暂停' : '播放' }}
      </button>
```

## 三、预测指标设计

### 3.1 指标定义

| 指标           | 业务意义               | 单位        | 可视化方式 | 地图图层类型  |
| -------------- | ---------------------- | ----------- | ---------- | ------------- |
| 吞吐量预测     | 港口货物吞吐量发展趋势 | 万吨        | 热力图     | Heatmap Layer |
| 泊位利用率预测 | 泊位使用效率           | %           | 颜色渐变点 | Vector Layer  |
| 船舶流量预测   | 进出港船舶数量         | 艘次/月     | 流线图     | Vector Layer  |
| 物流压力指数   | 综合物流负荷评估       | 指数(0-100) | 区域填充   | Vector Layer  |
| 港口发展指数   | 综合发展潜力评估       | 指数(0-100) | 区域填充   | Vector Layer  |

### 3.2 指标详细说明

#### 3.2.1 吞吐量预测（throughput）

- **业务意义**：预测未来港口货物吞吐量，反映港口规模发展趋势
- **数据来源假设**：历史吞吐量 + 区域 GDP 增长率 + 贸易总额 + 政策支持系数
- **地图图层**：热力图，颜色深浅表示吞吐量大小
  - 0-1000 万吨 → 绿色
  - 1000-5000 万吨 → 黄色
  - 5000-10000 万吨 → 橙色
  - 10000+ 万吨 → 红色

#### 3.2.2 泊位利用率预测（berth）

- **业务意义**：预测泊位使用效率，识别瓶颈泊位
- **数据来源假设**：泊位数量 + 船舶到港数量 + 平均停泊时间
- **地图图层**：颜色渐变点
  - 0-50% → #52c41a（充足）
  - 50-80% → #faad14（正常）
  - 80-100% → #f5222d（紧张）

#### 3.2.3 船舶流量预测（traffic）

- **业务意义**：预测进出港船舶数量，反映港口活跃度
- **数据来源假设**：历史 AIS 数据 + 航线规划 + 季节性系数
- **地图图层**：流线图，箭头粗细表示流量大小

#### 3.2.4 港口物流压力指数（pressure）

- **业务意义**：综合评估港口物流负荷，识别拥堵风险
- **计算公式**：`pressureIndex = throughput×0.4 + berthUtil×0.3 + roadCongestion×0.2 + railCongestion×0.1`
- **地图图层**：区域填充
  - 0-40 → 绿色（低压）
  - 40-60 → 黄色（中压）
  - 60-80 → 橙色（高压）
  - 80-100 → 红色（极高压）

#### 3.2.5 港口发展指数（development）

- **业务意义**：综合评估港口发展潜力，为投资决策提供参考
- **计算公式**：`devIndex = throughputGrowth×0.3 + berthExpansion×0.2 + regionalEconomy×0.3 + policySupport×0.2`
- **地图图层**：区域填充
  - 0-40 → 绿色（低潜力）
  - 40-60 → 黄色（中潜力）
  - 60-80 → 蓝色（高潜力）
  - 80-100 → 紫色（极高潜力）

## 五、后端接口设计

### 5.1 接口总览

| 接口                       | 方法 | 说明             | 使用场景   |
| -------------------------- | ---- | ---------------- | ---------- |
| `/forecast`                | GET  | 预测数据总览     | 页面初始化 |
| `/forecast/map`            | GET  | 地图图层 GeoJSON | 地图渲染   |
| `/forecast/:portId`        | GET  | 指定港口预测数据 | 港口详情   |
| `/forecast/indicator/:type`| GET  | 指定指标数据     | 图表渲染   |
| `/forecast/timeseries`     | GET  | 时间序列数据     | 折线图     |

> **注意**：客户端 API 路径**不带** `/api` 前缀。`useApiRequest` 内部会自动拼接 `VITE_API_BASE=/api`。例如 `apiRequest('/forecast/timeseries')` 实际请求 `/api/forecast/timeseries`。

### 5.2 接口详细设计

#### 5.2.1 GET /forecast

**请求参数**：无

**返回**：

```json
{
  "code": 200,
  "data": {
    "metadata": { "ports": [...], "indicators": [...] },
    "timeRange": {
      "historical": { "start": "2018-01", "end": "2025-12" },
      "forecast": { "start": "2026-01", "end": "2035-12" }
    }
  }
}
```

#### 5.2.2 GET /forecast/map

**请求参数**：`?indicator=throughput&time=2030-06`

**返回**：GeoJSON FeatureCollection，每个港口一个 Feature，properties 包含 `value` 和 `confidence`。

#### 5.2.3 GET /forecast/:portId

**请求参数**：`portId`（路径参数），`?indicator=throughput&start=2025-01&end=2030-12`（可选）

**返回**：该港口的历史+预测时间序列数据。

#### 5.2.4 GET /forecast/indicator/:type

**请求参数**：`type`（路径参数），`?time=2030-06&portId=qinzhou`（可选）

**返回**：该指标下所有港口的数据。

#### 5.2.5 GET /forecast/timeseries

**请求参数**：`?indicator=throughput&portId=qinzhou&granularity=month`

**返回**：时间序列数据，包含历史+预测。

#### 5.3.2 控制器

```javascript
// server/controllers/forecastController.js
import {
  getMapData,
  getPortData,
  getIndicatorData as queryIndicator,
  getTimeSeriesData as queryTimeSeries,
} from '../services/forecastService.js'
import { readFile } from 'fs/promises'
import { join, dirname } from 'path'
import { fileURLToPath } from 'url'

const __dirname = dirname(fileURLToPath(import.meta.url))
const DATA_PATH = join(__dirname, '../../public/data/forecast/index.json')

export async function getForecastOverview(req, res) {
  try {
    const data = JSON.parse(await readFile(DATA_PATH, 'utf-8'))
    res.json({ code: 200, data })
  } catch (error) {
    res.status(500).json({ code: 500, error: error.message })
  }
}

export async function getForecastMapData(req, res) {
  try {
    const { indicator, time } = req.query
    if (!indicator || !time) {
      return res.status(400).json({ code: 400, error: '缺少参数: indicator, time' })
    }
    const data = await getMapData(indicator, time)
    res.json({ code: 200, data })
  } catch (error) {
    res.status(500).json({ code: 500, error: error.message })
  }
}

export async function getPortForecast(req, res) {
  try {
```

```javascript
import { readFile } from 'fs/promises'
import { join, dirname } from 'path'
import { fileURLToPath } from 'url'

const __dirname = dirname(fileURLToPath(import.meta.url))
const DATA_DIR = join(__dirname, '../../public/data/forecast')

async function readDataFile(filename) {
  return JSON.parse(await readFile(join(DATA_DIR, filename), 'utf-8'))
}

export async function getMapData(indicator, time) {
  const data = await readDataFile(indicator + '.json')
  const features = []

  for (const portId in data.data) {
    const portData = data.data[portId]
    const spatial = portData.spatial
    if (spatial?.features) {
      for (const feature of spatial.features) {
        const value = feature.properties.values[time]
        if (value !== undefined) {
          features.push({
            type: 'Feature',
            geometry: feature.geometry,
            properties: {
              portId: feature.properties.portId,
              portName: feature.properties.portName,
              value,
              confidence: portData.forecast.find((f) => f.time === time)?.confidence || 1,
            },
          })
        }
      }
    }
  }

  return { indicator: data.indicator, unit: data.unit, time, type: 'FeatureCollection', features }
}

export async function getPortData(portId, indicator, start, end) {
  const indicators = indicator
    ? [indicator]
    : ['throughput', 'berth', 'traffic', 'pressure', 'development']
  const result = { portId, portName: '', indicators: {} }

  for (const ind of indicators) {
    const data = await readDataFile(ind + '.json')
    const portData = data.data[portId]
    if (!portData) continue

    if (!result.portName && portData.spatial?.features?.[0]) {
      result.portName = portData.spatial.features[0].properties.portName
    }

    let historical = portData.historical
    let forecast = portData.forecast
    if (start) {
      historical = historical.filter((d) => d.time >= start)
      forecast = forecast.filter((d) => d.time >= start)
    }
    if (end) {
      historical = historical.filter((d) => d.time <= end)
      forecast = forecast.filter((d) => d.time <= end)
    }

    result.indicators[ind] = { unit: data.unit, historical, forecast }
  }

  return result
}

export async function getIndicatorData(type, time, portId) {
  const data = await readDataFile(type + '.json')
  const result = { indicator: data.indicator, unit: data.unit, ports: {} }
  const ports = portId ? [portId] : Object.keys(data.data)

  for (const pid of ports) {
    const portData = data.data[pid]
    if (!portData) continue
    const portName = portData.spatial?.features?.[0]?.properties?.portName || pid
    let value = null
    if (time) {
      const point =
        portData.historical.find((d) => d.time === time) ||
        portData.forecast.find((d) => d.time === time)
      value = point?.value || null
    }
    result.ports[pid] = {
      portName,
      value,
      historical: portData.historical,
      forecast: portData.forecast,
    }
  }

  return result
}

export async function getTimeSeriesData(indicator, portId, start, end, granularity) {
  const data = await readDataFile(indicator + '.json')
  const ports = portId ? [portId] : Object.keys(data.data)
  const series = []

  for (const pid of ports) {
    const portData = data.data[pid]
    if (!portData) continue
    const portName = portData.spatial?.features?.[0]?.properties?.portName || pid
    let allData = [...portData.historical, ...portData.forecast]
    if (start) allData = allData.filter((d) => d.time >= start)
    if (end) allData = allData.filter((d) => d.time <= end)

    if (granularity === 'year') {
      const yearly = {}
      allData.forEach((d) => {
        const y = d.time.split('-')[0]
        if (!yearly[y]) yearly[y] = { time: y, value: 0, count: 0, type: d.type }
        yearly[y].value += d.value
        yearly[y].count++
      })
      allData = Object.values(yearly).map((d) => ({
        time: d.time,
        value: Math.round(d.value / d.count),
        type: d.type,
      }))
    }

    series.push({ portId: pid, portName, data: allData })
  }

  return { indicator: data.indicator, unit: data.unit, granularity: granularity || 'month', series }
}
```

### 8.2 useForecastLayer composable

```javascript
// src/business/forecast/composables/useForecastLayer.js
/**
 * useForecastLayer - 预测图层管理
 *
 * 职责：
 * 1. 根据 activeIndicator 和 currentTime 请求 GeoJSON 数据
 * 2. 通过 renderer 添加/更新预测图层
 * 3. 通过 useLayerManager 注册到图层目录（可在图层控制面板中切换）
 *
 * 架构约束：
 * - 通过 useMapControls 获取渲染器（与 SiteSelectionPage 一致）
 * - 通过 useLayerManager 注册图层（与现有图层管理机制一致）
 * - 不直接调用 map.addLayer()
 */
import { inject, computed } from 'vue'
import { useForecastState } from '@/stores/forecastState'
import { useLayerManager } from '@/core/map/composables/useLayerManager'
import { useApiRequest } from '@/shared/composables/useApiRequest'

export function useForecastLayer() {
  const forecastState = useForecastState()
  const unifiedMapRef = inject('unifiedMap', null)
  const { registerToggleable } = useLayerManager()
  const { apiRequest } = useApiRequest()

  const currentLayerKey = 'forecast-layer'

  /** 获取当前渲染器 */
  function getRenderer() {
    return unifiedMapRef?.value?.getRenderer?.() || null
  }

  /** 根据指标获取图层样式配置 */
  function getLayerConfig(indicator) {
    const configs = {
      throughput: { type: 'heatmap', radius: 20, blur: 15 },
      berth: {
        type: 'point',
        colorFn: (v) => (v > 80 ? '#f5222d' : v > 50 ? '#faad14' : '#52c41a'),
      },
      traffic: { type: 'line', widthFn: (v) => Math.max(2, v / 100) },
      pressure: {
        type: 'polygon',
        colorFn: (v) => (v > 80 ? '#f5222d' : v > 60 ? '#fa8c16' : v > 40 ? '#faad14' : '#52c41a'),
      },
      development: {
        type: 'polygon',
        colorFn: (v) => (v > 80 ? '#722ed1' : v > 60 ? '#1890ff' : v > 40 ? '#faad14' : '#52c41a'),
      },
    }
    return configs[indicator] || configs.throughput
  }

  /** 更新预测图层 */
  async function updateForecastLayer() {
    const renderer = getRenderer()
    if (!renderer) return

    const indicator = forecastState.activeIndicator
    const time = forecastState.currentTime

    try {
      const response = await apiRequest(
        `/forecast/map?indicator=${indicator}&time=${time}`,
      )

      if (response.code !== 200) return

      const geojson = response.data

      // 移除旧图层
      removeForecastLayer()

      // 根据指标类型添加图层
      const config = getLayerConfig(indicator)

      if (indicator === 'throughput') {
        // 热力图：使用 addHeatmapLayer（如果渲染器支持）或 addGeoJsonLayer
        renderer.addGeoJsonLayer(currentLayerKey, geojson, {
          type: 'heatmap',
          weight: 'value',
          radius: config.radius,
          blur: config.blur,
        })
      } else if (indicator === 'berth' || indicator === 'traffic') {
        // 点/线图层
        renderer.addGeoJsonLayer(currentLayerKey, geojson, {
          type: config.type,
          style: (feature) => ({
            color: config.colorFn ? config.colorFn(feature.get('value')) : '#409eff',
            width: config.widthFn ? config.widthFn(feature.get('value')) : 2,
          }),
        })
      } else {
        // 面图层（pressure / development）
        renderer.addGeoJsonLayer(currentLayerKey, geojson, {
          type: 'polygon',
          style: (feature) => ({
            fillColor: config.colorFn(feature.get('value')),
            fillOpacity: 0.5,
            color: config.colorFn(feature.get('value')),
            width: 2,
          }),
        })
      }

      // 注册到图层目录（使图层控制面板可以切换）
      registerToggleable(currentLayerKey, '预测图层', renderer)

      // 记录当前图层 key
      forecastState.activeForecastLayer = currentLayerKey
    } catch (e) {
      if (import.meta.env.DEV) console.error('更新预测图层失败:', e)
    }
  }

  /** 移除预测图层 */
  function removeForecastLayer() {
    const renderer = getRenderer()
    if (renderer) {
      renderer.removeLayer(currentLayerKey)
    }
    forecastState.activeForecastLayer = null
  }

  return {
    updateForecastLayer,
    removeForecastLayer,
  }
}
```

### 8.3 图层生命周期

```
页面挂载（onMounted）
    ↓
updateForecastLayer()
    ├── apiRequest('/forecast/map') → 获取 GeoJSON
    ├── renderer.addGeoJsonLayer() → 添加图层到渲染器
    └── registerToggleable() → 注册到图层目录

时间/指标变化（watch）
    ↓
updateForecastLayer()
    ├── removeForecastLayer() → renderer.removeLayer()
    ├── request() → 获取新数据
    ├── renderer.addGeoJsonLayer() → 添加新图层
    └── registerToggleable() → 重新注册

页面卸载（onUnmounted）
    ↓
removeForecastLayer()
    └── renderer.removeLayer() → 清理图层
```

## 十、性能设计

### 10.1 前端缓存

```javascript
// forecastState.dataCache（Map 结构，按时间索引）
// 请求前检查缓存，避免重复请求
async function fetchData(time) {
  if (forecastState.dataCache.has(time)) {
    return forecastState.dataCache.get(time)
  }
  const data = await apiRequest('/forecast/map?indicator=...&time=...')
  forecastState.dataCache.set(time, data)
  return data
}
```

### 10.2 按需请求

- 不一次性加载所有时间数据
- 每次只请求当前时间点的数据
- 切换粒度时重新请求（年度数据量远小于月度）

### 10.3 图表优化

- 复用 `LineChart`/`BarChart` 组件（内部使用 `useECharts` composable）
- 通过 props 响应式更新（`watchSources` 自动触发 `setOption`）
- ECharts 实例在组件卸载时自动销毁（`useECharts` 已处理）

### 10.4 图层优化

- 更新图层前先 `removeLayer` 移除旧图层，避免重复叠加
- 通过 `useLayerManager` 注册，确保图层控制面板可以管理预测图层
