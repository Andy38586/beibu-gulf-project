### 单元一：土地覆盖数据采集与入库

- **修前钩子**：§4.0 第 2 条（land_use 零命中 = 数据不存在）。
- **做什么**：选一免费源——GlobeLand30（30m，webmap.cn 注册下载，2020 期）/ ESA WorldCover（10m，2020/2021 期）/ CNLUCC（resdc.cn）；GDAL 裁北部湾 bbox → 矢量化 → 入 `land_use` 表（`geometry(MultiPolygon,4490)` + GiST，策略照抄 `db-schema-gis.sql`）；导入脚本进 `tools/`（照抄 SRTM15+/OSM 管线体例，`v3-发展路径-2026-08-14.md` §3.2）。
- **修后判据**：`SELECT count(*), count(*) FILTER (WHERE ST_IsValid(geom)) FROM land_use;` 两值相等且 >0；`\d land_use` 含 GiST 索引；来源与采集日期登记进 `tools/db` 口径注释。
- **阳性对照**：导入脚本对故意截断的样例文件必须报错退出（防「静默 0 行也绿」）。
- **依赖**：无（卡后续所有单元）。

### 单元二：准则因子归一化面预物化

- **修前钩子**：无准则面表（随单元一后新增 grep 判据）。
- **做什么**：各准则（浸没风险/可达性/预测引力/土地适宜/运河因子）归一化评分面落表或物化视图；**加权查询时只做求和**（勘误 #5 口径）。
- **修后判据**：每准则一行记录（网格/分区 id + 归一化分）；改权重参数重查，响应时间不随权重数增长。
- **阳性对照**：删任一准则表 ⇒ 加权端点必须报缺因子而非静默出 0。
- **依赖**：单元一；因子数据部分来自现有域（flood_levels 251 档 / route 可达性 / forecast 指标）。

### 单元三：AHP 权重模块（判断矩阵 + 一致性检验）

- **修前钩子**：§4.0 第 1 条（ahp 零命中）。
- **做什么**：TS 纯函数：判断矩阵解析 → 特征向量法权重 → CR<0.1 一致性检验，不过检验直接拒收；后端 `common` 或新域内，附单测。
- **修后判据**：单测含阳性（一致矩阵过）+ 阴性（改一格即 CR 报警拒收）两组；**变异四式**贴 stdout。
- **阳性对照**：单元内自带（上述阴性组即阳性对照的反向）。
- **依赖**：无，可与单元一并行。

### 单元四：加权叠加分析端点

- **修前钩子**：§4.0 第 4 条（site-suitability 后端域不存在）。
- **做什么**：新后端域（controllers/services/repositories 分层照 01 §四）：入参 = AHP 权重组，出参 = GeoJSON 适宜性面/格网；HTTP 边界 DTO + zod；接口 <2s（与 task-registry 实测口径同基准）。

- **阳性对照**：权重全 0 / 和 ≠1 必须校验拒绝。
- **依赖**：单元二、三。

### 单元五：前端权重滑块联动图层
