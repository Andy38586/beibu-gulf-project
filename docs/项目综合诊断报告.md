## 一、项目概览

**定位**：面向北部湾港口群（钦州港、北海港、防城港）的 WebGIS 综合分析平台，Vue 3 + OpenLayers + Cesium + ECharts + Node.js。

**四大业务模块 → 完整决策链**：

| 模块 | 路由 | 引擎 | 功能 |
|------|------|:----:|------|
| 首页 Home | `/` | 2D | 港口运行态势展示 |
| 选址分析 SiteSelection | `/site-selection` | 2D | 空间决策分析 |
| 三维港口分析 GCSAnalysis | `/gcs-analysis` | 3D | 水位模拟、剖面、淹没、影响评估 |
| 预测分析 Forecast | `/forecast` | 2D | 时间趋势预测 |

**核心架构**：策略模式（MapRenderer 抽象基类 → OLRenderer/CesiumRenderer 实现）+ GCS 布局系统（Cell + PPS 定位）+ BusinessLayerManager。
