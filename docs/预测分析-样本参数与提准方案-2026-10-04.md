每港 66 个月无重复、无缺失、无 NaN（复算命令见 §五-①）。

**回测样本量**（不是训练样本，但决定精度结论的分辨率）：

- origin 2024-01~2026-06 共 **30 个**；horizon 12 个月；

## 二、参数总量（实测口径）

### 2.1 单个模型的参数个数（每条序列）

| 模型                                   | 参数构成                                           | 个数                   |
| -------------------------------------- | -------------------------------------------------- | ---------------------- |
| 线性基线（现役主力）                   | 截距 1 + 斜率 1 + 季节指数 12（归一后有效 11）     | 14 拟合                |
| └ 预测期实际使用                       | 上式 + 验证期偏差校正因子 1（`correction_factor`） | **15**                 |
| 阻尼 Holt-Winters（ETS，`lib/hw.cjs`） | α/β/γ/φ 4 + 季节状态 12 + 初始水平/趋势 2          | **18**（AICc 计 k=16） |
| 季节朴素基准（下限）                   | 去年 12 个月同月值                                 | **12**                 |

### 2.2 全链参数总量（现状）

| 口径                           | 计算                               | 数      |
| ------------------------------ | ---------------------------------- | ------- |
| 在役预测链（6 条序列，按胜者） | 5 条线性 ×15 + 1 条 ETS ×18        | **93**  |
| 若三模型全量报告               | 6×15 + 6×18 + 6×12                 | 270     |
| 回测过程拟合的参数次数         | 30 origin × 6 序列 ×（15+18+12）   | 8100    |
| ETS 网格搜索最坏评估次数       | 30 × 6 ×（6×5×5×6 组合 ×2 季节型） | 324,000 |

**参数/样本比**：15/48 ≈ 0.31（每参数约 3.2 个月数据）、18/48 = 0.375——参数侧不紧张。
真正的风险在**外推比**：66 个月 ↔ 114 个月预测期（2026-07~2035-12），且 2026-09 平陆运河通航后
结构变化未被模型吸收（产物自陈"无运河反事实基线"）。因此提准的重点是**数据结构变化 + 验证协议 + 区间**，
不是继续加模型参数。

### 2.3 当前精度（滚动回测 h1–12 平均 MAPE / MASE）

| 序列             | 线性              | ETS               | 季节朴素         | 产物胜者 |
| ---------------- | ----------------- | ----------------- | ---------------- | -------- |
| cargo · 钦州     | **6.25% / 0.88**  | 9.14% / 1.25      | 7.41% / 1.04     | 线性     |
| cargo · 北海     | **10.45% / 0.73** | 15.31% / 1.06     | 12.87% / 0.92    | 线性     |
| cargo · 防城     | **7.95% / 0.61**  | 9.67% / 0.76      | 9.17% / 0.73     | 线性     |
| container · 钦州 | 10.22% / 0.92     | 13.27% / 1.15     | **7.81% / 0.70** | 线性     |
| container · 北海 | 13.93% / 0.94     | **13.13% / 0.86** | 13.85% / 0.99    | ETS      |
| container · 防城 | **16.53% / 1.54** | 16.91% / 1.64     | 20.04% / 1.96    | 线性     |

两条必须先说清的现状缺陷：

1. **闸门只能让 ETS 替换线性，季节朴素赢了也上不了位**——钦州集装箱朴素 7.81% 显著优于现役线性
   10.22%，但 `selectModel` 的规则是"ETS 须同时优于线性与朴素"，朴素不是候选胜者 ⇒ **现役模型比
   一个已实现的基准更差却不换**。
2. **区间没有校准**：MAPE 只算点误差；`lib/backtest.cjs` 的 PICP（区间覆盖率）钩子存在、
   单测存在，但生产链没有传 `intervalFn` ⇒ 产物与前端 reliability 反映的是"步长 MAPE 折算"，
   不是名义置信水平的实际覆盖率。

> 以上两点的**作废条件**：若 `tools/forecast/throughput_model.cjs` 与产物在复算时不再呈现
> "钦州 container 线性 10.22 / 朴素 7.81"与 `picp` 缺省，则本段作废。

## 三、提准方案（按 ROI 排序，每项给验收判据）

### P0-1 组合预测接线（**已有实现，零新依赖**）

- 依据：`tools/forecast/lib/combination.cjs`（Bates & Granger 加权、因果权重）与
  `tools/forecast/__tests__/combination.test.mjs` 已在库，但全仓无人调用。
- 做法：以 `{线性, ETS, 季节朴素}` 为成员，用**只用已实现误差**的 inverse-MAPE 权重，
  同协议（同 origin、同 horizon）跑滚动回测；胜出规则与现有闸门同构（组合须严格优于当轮最好单模型才替换）。
- 验收：① 6 条序列中 ≥4 条组合 MAPE ≤ 现有胜者；② 任何序列不得恶化 >0.5pp；
  ③ 两次 `npm run forecast:model` 产物逐字节一致（md5 相同）。
- 风险：组合权重若用全期回测分数定，等于泄漏——必须走 `createWeightTracker` 的逐 origin 更新。

### P0-2 闸门修正：让"季节朴素"可当胜者

- 做法：`selectModel` 改为 `best of {linear, ets, seasonal_naive}`，并加最小改进门槛
  （≥0.5pp 才换，防抖）；`model_comparison.selected` 与 `backtest.selected_model` 同步。
- 验收：钦州 container 从 10.22% 切到 ≤7.81%，其余 5 条不因门槛抖动换模型（复算输出逐条列出）。
- 失效条件：若官方数据追加后朴素不再领先该序列，本条自动作废（门槛会保留线性）。

### P0-3 区间校准（PICP）

- 做法：回测时传 `intervalFn`，用**逐 origin 已实现误差的分步长经验分位数**构造 80% 区间
  （与 `lib/backtest.cjs` 的 PICP 钩子对接）；产物 `lower/upper` 改用该校准区间，
  前端 `reliability` 维持现有语义但基准数字换成分步长覆盖率。
- 验收：6 条序列 overall PICP ∈ [0.70, 0.90]（名义 0.80）；h12 区间宽度 ≤ 现宽度的 1.2 倍。

### P1-1 平陆运河情景层（**最大系统性偏差来源**）

- 现状：`model_info.canal_assumption` 自陈"未建模平陆运河（2026-09-16 已通航）"，
  即 2027 年起的预测是**无运河反事实**；对钦州/北海货量是结构性偏置，不是随机误差。
- 做法：按论文主线工单 F3 落分流情景（分流率 10/20/30%，锚点：长洲船闸 2025 下行 1.72 亿吨 ×
  目的地占比、2035 规划 9550 万吨、首日实测 1679.8 吨），UI 明确标注 baseline 与 scenario。
- 验收：情景开关改变 2027–2035 预测的百分比在产物中可复核；`model_info` 同步改写；
  不掩盖基线（baseline 与 scenario 两个口径并列可回放）。

### P1-2 数据扩容与外生变量（**最高杠杆**）

- 做法：向官方来源补 2019–2020 月份（训练段 48 → 72，覆盖疫情断点）；用
  `docs/钦州港基础设施容量评估-2026-09-27.md` 的通过能力做**上限截断**或回归因子；
  外生变量（GDP/固投/能力）只上"有月度来源"的，不上年度插值假数据。
- 验收：滚动回测 MAPE 改善且 DM 检验 p<0.1（`lib/evaluate.cjs` 已实现、未接线）；
  拿不到月度数据时**如实记未取证**，不用年度值插成月度。

### P2-1 稳健估计与显著性报告

- 做法：接入 `lib/evaluate.cjs` 的 DM 检验与 sMAPE/MASE 并列报告；对异常月（春节、疫情）
  用显式虚拟变量或稳健回归（Theil–Sen/Huber），不用"删点"来提分。
- 验收：每条模型对比给出 p 值；只有"MAPE 改善 + p<0.1"才允许换模型。

### P2-2 口径反腐

- 做法：README/答辩数字只从产物派生（`tools/forecast/run-all.mjs` 的字段映射已具备），
  删除手抄死数。
- 验收：`npm run forecast:recompute` 报告中的"论文数字 → 产物字段"与文档数字逐条一致。

## 六、失效条件

1. 官方输入更新（`cargo.json`/`container.json` 追加月份）→ §一、§2.3 数字与结论全部重算；
2. `lib/hw.cjs` 网格或 `lib/backtest.cjs` 协议改动 → §二参数个数与 §2.3 精度重算；
3. 平陆运河情景层落地后，`model_info.canal_assumption` 改写 → §P1-1 的"未建模"前提作废；
4. 面板/接口新增口径（如 reliability 语义变化）→ P0-3 的验收数字需同步重定。
