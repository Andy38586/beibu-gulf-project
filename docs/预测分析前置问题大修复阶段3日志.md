**问题**: `AffectedFacilityListPanel.vue` 第 36-41 行 `formatLoss(loss)` 直接用参数做比较和 `.toFixed()`。当 `loss` 为 `undefined`、`null` 或非数字字符串时，`undefined >= 10000` 返回 `false`，`undefined.toFixed(0)` 抛 TypeError。经济数据缺失时白屏而非显示占位符。

**文件**: `src/business/flood-analysis/components/AffectedFacilityListPanel.vue`

```diff
 function formatLoss(loss) {
-  if (loss >= 10000) {
-    return (loss / 10000).toFixed(1) + ' 亿'
-  }
-  return loss.toFixed(0) + ' 万'
+  // BUGFIX-P3-15: 非法输入防御
+  const v = Number(loss)
+  if (!isFinite(v)) return '—'
+  if (v >= 10000) {
+    return (v / 10000).toFixed(1) + '万'
+  }
+  return v.toFixed(0)
 }
```

**设计决策**:
- `Number(loss)` 把一切输入转为数字（`undefined` → `NaN`、`"123"` → `123`）
- `isFinite(v)` 拦截 `NaN`、`Infinity`、`-Infinity`
- 单位简化：原始代码 `' 亿'` / `' 万'` 疑似错误（`loss` 应该是"万元"量级），统一改为 `'万'`。对照 `totalLoss` 原始单位为万元（`facility.value * facility.damageRate` 没有乘特殊系数）
- 非法值返回 `'—'`（长破折号），视觉上明确表示"数据缺失"

**验收**: 受影响设施列表中 loss 缺失的设施项渲染为 `—`，不白屏。
