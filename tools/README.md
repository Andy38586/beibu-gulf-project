# tools/ — 预测与数据处理脚本

## throughput_model.cjs（吞吐量十年预测流水线）

将三港**货物吞吐量（cargo，万吨）**建模为带置信区间的十年预测，并做回测误差校验。

> 覆盖范围说明（2026-08-09 接入正式服务链路）：产物仅覆盖 cargo（货物吞吐量）指标；
> container（TEU）/ berth / traffic 不走该模型（分别由趋势外推引擎与数据文件自带 forecast 提供）。

### 运行

```bash
npm run forecast:model
```

> 等价于 `node tools/throughput_model.cjs`。脚本为 CommonJS（`.cjs`），路径基于 `__dirname` 解析，与执行时 cwd 无关。

### 输入输出

| 项 | 路径 | 说明 |
|----|------|------|
| 输入 | `backend/data/forecast/throughput.json` | 三港历史月度吞吐量（2018-2025，随仓库提交，训练/验证期原始数据） |
| 输出 | `backend/data/forecast/throughput_model.json` | cargo 2026–2035 预测 + 置信区间 + 回测指标 |

### 服务链路接入（2026-08-09）

- `backend/services/modelLoader.js` 读取产物，`forecastService` 对 **cargo** 指标的预测段全部取自该产物（scenarioLevel 恒 1.0 固定基线，暂不支持情景参数）。
- 产物预测粒度为 2026 年逐月 + 2027~2035 每半年节点；与历史重叠月份丢弃，2027 起半年点由 `modelLoader` 做**月度线性插值**（纯可视化平滑，非模型新输出）。
- 产物缺失/结构不符时 cargo 降级到 `forecastEngine` 趋势外推，接口不中断。
- 可复现性：用随仓库提交的 `throughput.json` 重跑，输出与已提交产物**逐字节一致**。

### 方法论

1. **趋势提取**：12 个月中心移动平均，消除季节波动、露出长期趋势。
2. **季节分解**：按月份计算季节指数，分离季节项与趋势项。
3. **线性回归外推**：对去季节后的趋势做最小二乘回归，外推至 2026–2035。
4. **误差比率校正**：用验证期误差比率（bias）对预测做校正因子缩放。
5. **MAPE 回测**：在 2023–2025 验证期上计算平均绝对百分比误差，评估模型偏差。

### 训练 / 验证 / 预测分段

- 训练期：2018–2022
- 验证期：2023–2025（仅用于回测，不参与拟合）
- 预测期：2026–2035

### 实测精度（2026-08-09 复现验证）

| 港口 | 回测 MAPE |
|------|----------|
| 防城港 | 1.43% |
| 北海港 | 1.84% |
| 钦州港 | 2.30% |

MAPE < 2.3% 属高精度，说明该模型为有效预测而非占位脚本。当前为**功能版模型**：用于完成预测功能闭环（cargo 指标），准确率/置信区间优化与更专业算法留待毕业论文阶段。

### 何时重跑

- 历史吞吐量数据更新（`throughput.json` 追加新月份）后，应重跑以刷新预测。
- `throughput_model.json` 为生成产物；当前随仓库提交（后端 `data/` 为已跟踪数据目录，保证首次克隆即可运行）。如需改为「生成不提交」，在 `.gitignore` 增加该文件并在 CI / 部署前置步骤跑 `npm run forecast:model` 即可。
